## 🚀 What I'm Building

### 🛡️ Nexora Finance

> **A fintech dashboard designed to make financial activity easier to understand, monitor and manage.**

Nexora combines a modern finance dashboard with a dedicated risk-management layer.

**Highlights:**

* 📊 Financial analytics dashboard
* 💳 Transaction monitoring
* 🚨 Overspending & due alerts
* 🛡️ Sentinel risk detection engine
* 📋 Persistent audit ledger
* 📈 Risk scoring & decision signals
* 🔐 Backend API architecture
* ☁️ Database-backed application

**Tech:** `React` `TypeScript` `Node.js` `PostgreSQL` `Supabase` `Drizzle`
